# Responsive Landing Page - Flutter Web

A modern, responsive, and fully adaptive landing page built using **Flutter Web (v3.29.2)**. Designed smooth animations, and scalable architecture.

---

## Features

-  Fully Responsive Layout (Desktop, Tablet, Mobile)
-  Auto-Scrolling Animation for "Trusted Companies" Section
-  Modern UI with clean components and smooth transitions
-  Lightweight and optimized for performance
-  Built using Flutter Web (v3.29.2)
